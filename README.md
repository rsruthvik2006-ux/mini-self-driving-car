# Mini Self-Driving Car 🚗🤖

A miniature autonomous vehicle powered by a **Raspberry Pi**, using **OpenCV** for real-time lane detection and **PyTorch** for object/sign recognition.

---

## 🛠️ Hardware Stack
* **Processing:** Raspberry Pi 4/5 (8GB RAM)
* **Vision:** Raspberry Pi Camera Module 3
* **Actuation:** L298N Motor Driver + DC Gear Motors + Steering Servo
* **Power:** Separate 5V LiPo battery for motors, power bank for Raspberry Pi
